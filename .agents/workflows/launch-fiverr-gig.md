## New Fiverr Gig Workflow

1. Identify the service to package
   - Review the relevant `services/[pillar]/README.md`
   - Pick a specific, deliverable service (not too broad)

2. Define the 3 pricing tiers
   - Reference `operations/finance/pricing-guide.md`
   - Set Basic / Standard / Premium with clear differentiators

3. Write the gig description
   - Use the prompt from `skills/ai-prompts/master-prompts.md` → "Fiverr Gig Description Writer"
   - Fill in: service, deliverables, turnaround, differentiator, target buyer

4. Create the gig cover image
   - Use Canva: Bold text, mockup of deliverable, strong contrast
   - Include result/outcome text, not just the service name

5. Write 3 FAQ answers
   - Address: "What do I need to provide?", "How many revisions?", "Can you do [related thing]?"

6. Set the tags/keywords
   - Use 5 Fiverr-allowed tags — research top gigs in the category for inspiration

7. Publish the gig

8. Share the gig link on LinkedIn with a brief post about the service
   - Use the social media caption prompt from `skills/ai-prompts/master-prompts.md`
