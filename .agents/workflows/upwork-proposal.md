## Upwork Proposal Workflow

// turbo-all

1. Read the job posting carefully — highlight:
   - The specific problem they're solving
   - Tools/platforms they mention
   - Any red flags (unclear budget, vague scope, no reviews)
   - Size of project and timeline

2. Check if this project matches a service we offer
   - Reference: `services/[relevant-pillar]/README.md`

3. Find relevant experience / past example to reference
   - Check: `clients/` directory for past projects

4. Write the proposal using the Upwork formula
   - Use prompt from `skills/ai-prompts/master-prompts.md` → "Upwork Proposal Writer"
   - Under 150 words. No generic openers. End with soft CTA.

5. Paste job description into the prompt → generate draft → refine

6. Add a portfolio link or relevant attachment if applicable

7. Submit with a custom greeting (use client name if visible)

8. Log the application in a tracking sheet (job title, date, rate quoted, status)

9. Follow up if no response after 5 days (one follow-up only)
