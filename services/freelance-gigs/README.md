## 🎯 Platform Strategy

### Primary Platforms
| Platform | Best For | Strategy |
|---|---|---|
| **Upwork** | Tech, automation, design, marketing | Long-term contracts, higher rates |
| **Fiverr** | Quick-turnaround packages, lower AOV | Volume play, strong portfolio |
| **LinkedIn** | Direct outreach, professional clients | Relationship-based, highest rates |
| **Toptal** | Elite clients, premium rates | Requires application/vetting |
| **PeoplePerHour** | UK/EU market, mixed services | |

### Platform Tiers (Focus in Order)
1. **LinkedIn** (direct outreach — highest value, no fees)
2. **Upwork** (steady inbound pipeline)
3. **Fiverr** (volume + reviews early on)

## 🏆 Getting The First 10 Reviews

Phase 1 (Reviews Collection):
1. Set Fiverr prices at 30–50% below market
2. Deliver above and beyond (over-communicate, fast delivery)
3. Ask for a review at delivery: *"If you're happy with the work, a review helps me a lot!"*
4. On Upwork: apply to 5–10 jobs/day with custom proposals

Phase 2 (Building Reputation):
- Collect 10 reviews → raise prices 20%
- Collect 25 reviews → raise prices another 20%
- Get Fiverr Level 1/2 badge → algorithmically boosted

## ✍️ Proposal Templates

### Upwork Proposal Formula
```
Opening: Reference something specific about their project
          (NOT "Hi, I'm [name] with X years experience...")

Line 2: State your relevant skill/experience (1 sentence)

Lines 3–5: Explain exactly what you'd do for their project
           (show you read the brief)

Line 6: Social proof — quick result/win from similar work

CTA: "Happy to share some examples — want to jump on a 15-min call
     this week?"
```

**Example:**
> Saw you're looking to automate your lead intake process — this is exactly what I built for an e-commerce client last month that saved them 8 hours/week.
>
> I'd connect your Typeform → HubSpot → send a personalized email sequence automatically. Full build in n8n, fully documented.
>
> Previous project like this: went from 0 to live in 4 days, client called it "the best money they've ever spent."
>
> Can share the case study — open for a quick 15-min call this week?

---

### Fiverr Gig Description Formula
```
HEADLINE: Specific result you deliver
HOOK: Who this is for + main pain point
WHAT YOU GET: Bullet list of deliverables
WHY ME: 1–2 lines of credibility
PROCESS: Simple 3-step process
CTA: "Order now" or "Message me first"
```

## 📌 Profile Optimization Checklist

### Upwork Profile
- [ ] Headline = specific skill + outcome (not job title)
- [ ] Overview = AIDA format, client-focused, no fluff
- [ ] Portfolio = 3–5 best projects with results
- [ ] Hourly rate = competitive for niche (research top 10 in category)
- [ ] Tests = take relevant Upwork skill tests
- [ ] Availability = set to 30 hrs+/wk while building

### Fiverr Profile
- [ ] Profile photo = professional, smiling, solid background
- [ ] Bio = short, confident, outcome-focused
- [ ] Gig titles = keyword-rich, specific, benefit-led
- [ ] Gig images = bold, clear, professional mockups
- [ ] FAQ filled out = reduces buyer questions, builds trust
- [ ] Packages = 3 tiers always (anchors the middle option)
