## New Client Onboarding Workflow

1. Get the "yes" (verbal/message/payment)

2. Send the welcome message within 2 hours
   - Use template from `operations/SOPs/client-onboarding.md` → Step 1

3. Create a client folder
   - Duplicate `clients/_template/` → rename to `clients/[client-name]/`
   - Fill in `brief.md` with all discovery notes

// turbo
4. Send onboarding questionnaire within 24 hours
   - Use the relevant questionnaire from the service playbook
   - Tool: Tally.so or Google Forms

5. Send deposit invoice (50% upfront for projects over $300)
   - Tool: Wave or Stripe

6. Once deposit received → send kick-off confirmation
   - Use template from `operations/SOPs/client-onboarding.md` → Step 5

7. Set deadline reminder in calendar (3 days buffer built in)

8. Begin project work per the relevant service playbook
