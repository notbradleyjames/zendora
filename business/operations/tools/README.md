# 🛠️ Zendora Tools Center

> *Autonomous folders for every tool we use in Zendora.*

---

## 🗂️ How This Directory Works

Instead of one massive file that gets outdated quickly, each tool lives in its own folder:
`business/operations/tools/[tool-name]/`

### 📜 Inside Each Tool Folder
Whenever a new tool is introduced to Zendora, we create a folder for it. Inside you will find:
1. **`README.md`**: The source of truth for that specific tool. It details:
   - What we use it for (Purpose)
   - Which plan we subscribe to (Cost/Plan)
   - Zendora-specific guidelines, limitations, and how-tos.
2. **`data/`**: A subdirectory for storing output logs, configuration JSONs, export files, or complex reference materials associated with that tool.

### 🔍 Finding Tools
There is no central index to keep updated. Just browse this folder using the file explorer or your terminal.
- Need ChatGPT usage? Check `chatgpt/`
- Want to read about Firecrawl? Check `firecrawl/`
