## Usage

All Zendora client code, internal automation configurations (like exported n8n JSONs), and documentation is hosted and versioned on GitHub.

- **Storage**: n8n workflow exports should be committed here.
- **Collaboration**: When building automations with contractors or clients, this serves as the source of truth.
