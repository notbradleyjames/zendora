# 🚀 Project Delivery SOP

> *How we close out projects with professionalism and panache.*

---

## Trigger
This SOP activates when all project work is complete and ready for client review.

---

## Pre-Delivery Checklist

Before sending anything to a client:

- [ ] Work matches everything in the `brief.md` scope
- [ ] No typos, broken links, or placeholder content
- [ ] All files are properly named (no "Final_FINAL_v3.png")
- [ ] Files are in the correct format requested
- [ ] A short Loom walkthrough has been recorded (even 2 min counts)
- [ ] Final invoice is ready to send (if applicable)
- [ ] Revision rounds have been tracked — how many remain?

---

## File Naming Convention

```
[ClientName]_[ProjectType]_[Component]_[Version].[ext]

Examples:
  AcmeCo_BrandKit_Logo_Final.svg
  JohnSmith_LandingPage_Design_v2.fig
  ZendoraDemo_AutomationFlow_Diagram.pdf
```

## Delivery Methods by Type

| Deliverable | Method |
|---|---|
| Design files (Figma) | Share Figma link + export PNG/SVG/PDF |
| Design exports | Google Drive folder (organized) |
| Automation (n8n) | Share JSON export + Loom walkthrough |
| Copy/documents | Notion page or Google Doc (view access) |
| Video | Loom link or Google Drive |
| Social templates | Canva shared link OR Figma |
| Reports | PDF via email OR Notion |

## Delivery Message Sequence

### Message 1 — Delivery
Send immediately when ready.

```
Subject: ✅ [PROJECT NAME] — Delivered!

Hi [NAME],

Your project is ready! Everything has been completed as discussed.

Here's what's included:
📁 Files: [LINK]
🎥 Walkthrough: [LOOM LINK]
📄 Summary: [BRIEF DESCRIPTION OF WHAT WAS DELIVERED]

[If revisions remain]: You have [X] revision round(s) remaining. Feel free to share any feedback!

[If final balance due]: Invoice for the remaining $[AMOUNT] is attached. No rush — whenever works for you.

Let me know if you have any questions!

[Your name]
```

---

### Message 2 — Revision Request Response
If client requests changes:

```
Hi [NAME],

Got your feedback — thanks for the notes!

Here's what I'll be updating:
1. [CHANGE 1]
2. [CHANGE 2]
3. [CHANGE 3]

Anything I missed or anything else to add? Otherwise I'll have the updated version to you by [DATE].
```

---

### Message 3 — Final Delivery (After Revisions)
```
Hi [NAME],

Updated version is ready!  
📁 [New link / updated files]

This uses your final revision round. Any further changes beyond this would be quoted separately — but hopefully this is exactly what you had in mind!

[PAYMENT REMINDER if applicable]

Looking forward to hearing what you think!
```

---

### Message 4 — Follow-up for Review (3–5 days post delivery)
```
Hi [NAME],

Just wanted to check in — hope everything is going great with [PROJECT]!

If you're happy with the work, a quick review on [PLATFORM] would genuinely help a ton. Takes about 30 seconds:
👉 [REVIEW LINK]

And if you ever need anything else — or know someone who does — I'd love to stay in touch.

Thanks again for trusting me with this!

[Your name]
```

## Handling Common Delivery Scenarios

### Client Goes Silent After Delivery
Wait 5 days → send follow-up (Message 4 above).  
If no response after 10 days: mark project complete internally. Send final payment reminder.

### Client Asks for Out-of-Scope Changes
```
Hi [NAME], happy to make that change!

Just to flag — [REQUESTED CHANGE] is outside the original scope we agreed on, so I'd need to quote this separately.

For [THAT SPECIFIC CHANGE], I'd estimate [X hrs / $Y]. Want me to proceed?
```

### Client Wants More Revisions Than Included
```
Hi [NAME],

We've now used the [X] revision round(s) included in the project scope.

I'm happy to continue — additional revisions are priced at $[Y] per round. Want to proceed?
```

## Post-Project Closeout Checklist

- [ ] Delivery confirmed by client (or 10-day silence rule applied)
- [ ] Final payment received
- [ ] Files backed up to cloud storage
- [ ] Project log `project-log.md` updated and marked complete
- [ ] Testimonial requested + logged if received
- [ ] Client added to CRM with tags: service type, satisfaction, repeat potential
- [ ] Debrief written in project log
