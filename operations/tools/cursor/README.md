# 💻 Cursor

**Category:** Development & Code  
**Purpose:** AI-powered IDE that integrates MCP tools natively.  
**Plan:** Free / Pro  
**Cost:** $0 / $20/mo

---

## Usage

Cursor is our primary AI coding assistant. We use it to edit code, manage the codebase, and interact with the filesystem.

- **MCP Setup**: Cursor automatically reads from `.vscode/mcp.json`.
- **Workflows**: Leverage Cursor for running the `/insights` workflow, building n8n instances, and setting up Firecrawl automation.
